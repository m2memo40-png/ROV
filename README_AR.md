# مدير باقة Wi‑Fi — Android

## الوظائف الموجودة
- تحديد إجمالي الباقة بالجيجابايت.
- تحديد مدة الباقة بالأيام.
- PIN للمسؤول داخل التطبيق.
- قياس استهلاك Wi‑Fi عبر NetworkStatsManager بعد منح صلاحية Usage Access.
- تنبيهات عند 30% و60% و90%.
- حظر فعلي لاتصال الجهاز عبر VpnService عند وصول الاستهلاك للحد.
- تشغيل المراقبة بعد إعادة التشغيل.
- مؤشر Device Owner وحماية إعدادات الإدارة.

## مهم جداً
هذا الإصدار يقيس ويحظر **الجهاز الذي ثبّت عليه التطبيق**. لا يمكن لتطبيق Android عادي أن يفرض حد الجيجا على بقية أجهزة الراوتر من دون تكامل مع الراوتر (API/SNMP/مدير الشبكة) أو تحويل الجهاز إلى Gateway.

## البناء
افتح المشروع في Android Studio 2026.1.x ثم Build > Build APK(s).
المشروع يستخدم Android Gradle Plugin 9.4.0 وcompileSdk 36 وJava 17.

## أول تشغيل
1. ثبّت التطبيق.
2. افتح "صلاحية إحصاءات الاستخدام" وامنح التطبيق Usage Access.
3. اضغط "تفعيل حظر الإنترنت (VPN)" ووافق على إنشاء VPN.
4. اضبط الجيجا والمدة وPIN واضغط حفظ.
5. شغّل المراقبة.

لـ Device Owner استخدم إعداد إدارة أجهزة رسمي/جهاز اختبار، وليس تغييراً تلقائياً من التطبيق.
